## 今天的核心模型

```text
函数三问（写任何函数前先答）：
  ① 参数是什么类型？默认值会不会踩可变对象？
  ② 会不会就地改调用方的数据？该不该改？
  ③ 返回值是什么类型？有没有可能返回 None？

容器四件套：
  list  有序·可变·可重复   → 按"顺序"存东西
  tuple 有序·不可变         → 多返回值 / 固定组合
  dict  按 key 取           → 映射、计数、结构化数据
  set   去重、O(1) 查找      → 去重、交并差
```

**今天最重要的发现（比错题本身重要）**：

> 20 题有 `check()` 兜着 → **全对**；
> 微课 6 题没有 `check()` → **3.5 题、还有一个文件一跑就崩**。
> **不是你"会不会"的问题，是"有没有跑"的问题。** 这就是 D5 要学 pytest 的原因。

## 错题 1 · 写完没运行（微课 B2）—— 今天最大的问题

- **现象**：`micro_oop.py` 的 `from_dict` 里写 `data["tile"]`（应为 `"title"`）。直接运行：

  ```text
  KeyError: 'tile'
  ```

  脚本在 `t2 = Todo.from_dict(t.to_dict())` 这一行就崩了，**B3 的验证代码根本没执行到**。
- **错因**：**写完没运行**。这不是拼写问题 —— 拼写错谁都会有；问题是"拼错了却没有任何机制发现它"。
  同一份文件里你自己写了 `print(t2)` 的验证，但**没跑就等于没写**。
- **正确做法**：

  ```text
  写完 → 立刻 python xxx.py → 看到期望输出才叫"写完"
  崩了 → 先读 traceback 的最后一行（异常类型 + 信息），它基本直接告诉你错在哪
  ```

- **一句话记住**：**"写了"不等于"能跑"；"能跑"不等于"跑对"；只有"跑对"才算完。**

## 错题 2 · 题目要求没落实（微课 A1 / A2）

- **现象 A（A1）**：题目要求"返回**不转义中文**的 JSON"，我写 `json.dumps(obj)`。
  实测输出 `{"name": "\u6c64\u59c6"}` —— 中文被转义了，人无法阅读。
- **现象 B（A2）**：`load_json` 三个问题，最致命的是一个**永远返回 None** 的函数：

  ```python
  def load_json(path: str) -> object:
      with open(path, "r", encoding="utf-8") as f:
          loaded = json.load(f)
          if not load_json:        # ← 判断的是"函数对象"，恒为真
              return None
      # ← 这里少了 return loaded，所以永远返回 None
  ```

  而且没处理 `FileNotFoundError`（题目明确要求"文件不存在返回 None"）。
- **错因**：
  1. A1 是"**读题少读了半句**"（"不转义中文"这几个字）；
  2. A2 是"**把 `if not load_json` 当成了 `if not loaded`**" —— 变量名和函数名混了；而且还漏了 `return`。
- **正确写法**：

  ```python
  def to_json(obj: object) -> str:
      return json.dumps(obj, ensure_ascii=False)

  def load_json(path: str) -> object:
      try:
          with open(path, "r", encoding="utf-8") as f:
              return json.load(f)
      except FileNotFoundError:
          return None
  ```
- **一句话记住**：**写完把题目要求逐条对一遍（尤其是"不许/必须/不转义"这种限定词）。**

## 错题 3 · 元组往返 JSON 会变 list（微课 A3 ③④）

- **现象**：
  - ③ 我把结果写成 `["a", [1, 2]]` —— 实际是 **`{'a': [1, 2]}`**（外层还是 dict，只有元组变成了 list）。
  - ④ 我答的是"`dumps` / `loads` 操作字符串"（那是**记忆口诀**），没回答"会不会报错、报什么"。
- **错因**：把"口诀"当成了答案；对 ③ 连外层结构都没看清。
- **正确答案**：

  ```text
  ③ json.loads(json.dumps({"a": (1, 2)}))  →  {'a': [1, 2]}   ← 元组回不去了
  ④ json.dumps({(1, 2): "a"})  →  TypeError: keys must be str, int, float, bool or None, not tuple
  ```
- **一句话记住**：**JSON 里没有"元组"，只有 array；JSON 的 key 只能是字符串（或数字/布尔/None）。**

## 错题 4 · 逻辑对了，但没自证（ex19）

- **现象**：三个改错题的函数我**都改对了**：

  | 函数 | 我的改法 | 对不对 |
  |---|---|---|
  | `add_tag` | `tags=None` + `if tags is None: tags = []` | ✅ |
  | `copy_tags` | `return sorted(tags)` | ✅（能改不动原列表；不过是"顺带排序"的副本） |
  | `first_even` | `return -1` 挪到循环外 | ✅ |

  但 `ex19_fix_errors() -> str` **最后没有调用这三个函数、也没有 return** → 实测输出 `ex19: None`，类型注解写着 `-> str` 却返回 `None`。
- **错因**：**改对了，但没让它自证**。改错题的价值有一半在"改完能证明它对了"。
- **正确做法**：在函数末尾加自测（这就是 D5 的 pytest 要自动化的东西）：

  ```python
  def ex19_fix_errors() -> str:
      ...
      results = [
          add_tag("a") == ["a"],          # True
          add_tag("b") == ["b"],          # True（不累积）
          first_even([1, 3, 4]) == 4,
          first_even([1, 3]) == -1,
      ]
      return f"{sum(results)}/4 通过"
  ```

## 必须能脱口而出的 5 句话

1. **默认参数不要用可变对象**（`[]` / `{}` / `set()`），用 `None` 占位、函数内再创建。
2. 函数里**给名字赋值**就会让它变局部 → `counter = counter + 1` 报 `UnboundLocalError`；要改全局得传进传出（别用 `global`）。
3. `items.append(x)` 会**就地改**调用方的列表；`items = items + [x]` 不会。
4. **类属性是所有实例共享的**；只有 `self.x = ...`（赋值）才创建实例属性；`self.items.append` 是就地改，不改共享。
5. **写完必须运行**：不跑 = 没写。跑崩了先看 traceback 最后一行。
