## 错题 1 · `and` / `or` 返回的是操作数本身（今天错了 **4 次**）

- **现象**（4 处，全是同一个概念）：
  | 我写的代码 | 我的预测 | 实际 |
  |---|---|---|
  | `"a" and "b"`（demo 3-b） | `"a"` | **`"b"`** |
  | `True and boom()`（demo 4-c） | `True` | **`"boom"`** |
  | `True and boom()`（ex03-c） | `True` | **`boom`** |
  | `None or []`（ex12 预测 4） | `None` | **`[]`** |
- **错因**：我把 `and`/`or` 当成 C/Java 的 `&&`/`||` —— 那两个返回布尔值。**Python 里它们返回操作数本身。**
  最讽刺的是：`ex02` 的解释我写得**一字不差**（"or/and 返回处理结果操作数"）—— 规则背下来了，一到具体表达式就退回布尔直觉。
- **规则（背下来）**：

  ```text
  A and B ：A 为假 → 返回 A ；A 为真 → 返回 B
  A or  B ：A 为真 → 返回 A ；A 为假 → 返回 B
  一句话：从左往右算，返回第一个"能定局"的那个操作数本身。
  ```

- **自己跑一遍记住它**：

  ```python
  print("a" and "b")     # b
  print(0 or "默认")      # 默认
  print(None or [])      # []
  print(1 and 2)         # 2
  print("")              # 空行（空串本身也是假值）
  ```

- **变式**：`variants.py` v1 五连问 —— **全对 ✅**（这条规则现在能用了）

## 错题 2 · 真值判断：`s is ""` 为什么不行（ex06）

- **现象**：题目要求"用真假值判断空串，**不许用 `==`**"，我写成了：

  ```python
  if s is "":        # ← 错
  ```

- **错因（两层）**：
  1. 我把"不许用 `==`"理解成"**换一个运算符**"，但题目要的是**换思路** —— 用真假值判断，而不是跟空串比较。
  2. `is` 比的是**身份**（是不是同一个对象），不是内容。Python 为此专门警告：

     ```text
     SyntaxWarning: "is" with 'str' literal. Did you mean "=="?
     ```

     教练实测：`"" is ""` 现在**确实**返回 `True`（CPython 把空串做成了单例）—— **它只是碰巧没坏**，属于依赖实现细节的写法。
- **正确写法**：

  ```python
  s = ""
  if not s:          # 空串是假值 → "有内容" 就是 s 为真
      print("空")
  else:
      print("非空")
  ```

- **假值清单（必须背，只有这 8 个）**：

  ```text
  False   None   0   0.0   ""   []   ()   {}
  ```

  两个反直觉的：`bool("0")` → `True`（非空字符串）；`bool([0])` → `True`（非空列表）。
- **变式**：`variants.py` v4 真值六连问（`""` `"0"` `0` `[]` `[0]` `None`）—— **全对 ✅**

## 错题 3 · `//` 拿份数、`%` 拿剩余；**基数要跟着题目走**

- **现象 A（ex10 秒数拆分）**：我写 `total //= 3600`，把 3725 变成了 **1**（"有几个 3600"），而下一步需要的是 **125**（"还剩多少秒"）→ 输出 `[1, 0, 0]` 全错。
- **现象 B（variants v2 分钟拆分）**：题目是**分钟 → (天, 时, 分)**，我把 ex10 的 `3600` **照抄**过来，可 1 天 = **1440** 分钟 → 实测 `(0, 25, 0)`（docstring 明明写着 `1500 → (1, 1, 0)`）；`merge` 也是 `days * 3600` → `3660`（应 1500）。
- **错因**：
  1. 没分清 `//`（拿份数）和 `%`（拿剩余）的分工；
  2. 变式题**照抄上一题的常数**，没看自己写的 docstring；
  3. 忘了变式题的意义就是"**同结构、换数据**"—— 照抄代码等于交白卷。
- **正确写法（ex10 版，换单位只需换基数）**：

  ```python
  h = total // 3600
  total %= 3600      # ← 关键：拿"剩余"，不是"份数"
  m = total // 60
  total %= 60
  s = total
  return (h, m, s)
  ```

- **口诀**：**`//` 拿份数，`%` 拿剩余；基数看单位**（秒→时 3600、分钟→天 1440、分钟→时 60）。
- **变式**：`variants.py` v2（待修：基数改 1440/60）

## 错题 4 · 写完不对答案（今天 3 次事故）—— 流程错，不是知识错

| 事故 | 屏幕上的实际输出 | 我文件里写着的 |
|---|---|---|
| `ex12` 预测 4 / 5 | `[]` / `-4 2 False` | `None` / `-4 -3 False` |
| `ex03-c` | `boom` | `True` |
| `variants` v2 | `(0, 25, 0)` | docstring 期望 `(1, 1, 0)` |

- **正确做法（四步，缺一不可）**：写预测 → 运行 → **逐行对着自己的预测读一遍输出** → 对不上的当场划掉改写 + 记进错题本。
- **工具：让机器替你划勾**（贴在文件顶部，以后所有预测题都用它）：

  ```python
  def check(label: str, actual: object, guess: object) -> None:
      print(label, "实际=", actual, "预测=", guess, "对上了吗:", actual == guess)


  check("ex03-c", True and boom(), "boom")
  # 输出： ex03-c 实际= boom 预测= boom 对上了吗: True
  ```

  **眼睛对答案会漏（今天漏了 3 次）；让程序对答案不会漏。**
  D5 要学的 `pytest`，本质就是 `check` 的正式版。
