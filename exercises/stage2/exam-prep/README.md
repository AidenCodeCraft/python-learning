## 四、考试当场的三个"保命"动作

1. **先跑通环境再做题**：`redis.Redis(...).ping()`、`pymysql.connect(...)` 能连上，再动业务代码。
2. **每个操作后验证结果**（考点强调"能验证"）：写完 INSERT 就 `SELECT` 一下；写完 Redis 就 `GET` 一下。
3. **SQL 一律参数化**（`%s`），Redis 的 key 拼 f-string 没关系（Redis 没有注入概念，但注意 key 命名规范）。
