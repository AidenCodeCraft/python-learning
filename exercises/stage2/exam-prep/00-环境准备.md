> 目标：本机起一个 Redis + 装好 `redis` / `pymysql` 两个包，并能连上公司的 MySQL。

## 第 1 步：起 Redis（本机 Docker）

1. 打开 **Docker Desktop**，等鲸鱼图标变绿（约 1~2 分钟）
2. 执行：

```powershell
docker run -d --name exam-redis -p 6379:6379 redis:7
docker ps            # 看到 exam-redis 且 STATUS 是 Up 就行
```

3. 验证（不装客户端也能验）：

```powershell
docker exec -it exam-redis redis-cli ping      # 返回 PONG
```

> 如果公司电脑也有 Redis，可以直接连公司内网地址，把下面代码里的 `host` 换掉即可。
> 停止 / 删除：`docker stop exam-redis` / `docker rm -f exam-redis`

## 第 3 步：验证 Redis 能连

```powershell
python -c "import redis; r=redis.Redis(host='127.0.0.1', port=6379, db=0, decode_responses=True); print(r.ping()); r.set('k','v'); print(r.get('k'))"
```

预期：`True` 然后 `v`。

## 第 6 步：连接信息统一写进一个文件

新建 `exercises/stage2/exam-prep/my_config.py`（不要提交含真实密码的文件到公开仓库）：

```python
REDIS_CONF = {"host": "127.0.0.1", "port": 6379, "db": 0, "decode_responses": True}
MYSQL_CONF = {
    "host": "127.0.0.1",
    "port": 3306,
    "user": "root",
    "password": "123456",
    "database": "school",
    "charset": "utf8mb4",
    "cursorclass": "DictCursor",   # 实际用的时候换成 pymysql.cursors.DictCursor
}
```

后面所有示例都用这两个配置。

## 卡住时的排查顺序

| 现象 | 检查 |
|---|---|
| `redis.exceptions.ConnectionError` | Docker 起了吗？`docker ps`；6379 端口监听了吗 |
| `pymysql.err.OperationalError (1045)` | 账号/密码错 |
| `(2003) Can't connect` | MySQL 没起 / 端口没映射 |
| `(1049) Unknown database 'school'` | schema.sql 没执行 |
| 中文乱码 | 连接参数加 `charset="utf8mb4"` |
