## 卡住时的排查顺序

| 现象 | 检查 |
|---|---|
| `redis.exceptions.ConnectionError` | `docker ps` 里 `exam-redis` 在不在？6380 端口监听了吗？ |
| `port is already allocated` | 6379 / 3306 已分别被 `ai-diagnostic-redis` / `practice-mysql` 占用，别再映射 |
| `pymysql.err.OperationalError (1045)` | 账号/密码错 |
| `(2003) Can't connect` | MySQL 没起 / 端口没映射 |
| `(1049) Unknown database 'school'` | `schema.sql` 没执行 |
| 中文乱码 | 连接参数加 `charset="utf8mb4"` |
| Python 输出中文乱码 / `UnicodeEncodeError` | PowerShell 先 `chcp 65001`；或设 `$env:PYTHONIOENCODING='utf-8'`（`redis_demo.py` 已做 replace 兜底） |
