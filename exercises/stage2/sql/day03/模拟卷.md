# Part A · 概念题（30 分，每题 3 分）

> 用一句话/几个词回答，写在纸上或文件里。

1. MySQL 默认的事务隔离级别是哪个？
2. ACID 中「持久性 D」靠什么日志实现？「原子性 A」呢？
3. `DELETE` / `TRUNCATE` / `DROP` 三者的区别（各一句话）？
4. 金额字段该用什么类型？为什么不用 `FLOAT`？
5. `utf8` 和 `utf8mb4` 的区别？
6. 主键和唯一索引的区别（至少说 2 点）？
7. 什么是「回表」？怎么避免？
8. 联合索引 `(name, age)` 能用于 `WHERE age = 20` 吗？为什么？
9. `INNER JOIN` 和 `LEFT JOIN` 的区别？`COUNT(*)` 和 `COUNT(右表.id)` 在 LEFT JOIN 下有什么不同？
10. 一条 SQL 缺了 `WHERE` 的 `UPDATE` 会发生什么？写 UPDATE 前的安全做法是什么？

# Part B · 写 SQL（55 分）

> 在 `practice` 库上做。每题写出完整 SQL。
> 每题 5 分，最后一题 10 分。**N/A 表示这题不要求注释**。

## 第一组：建表与增删改（20 分）

**B1（5 分）** 建表 `orders`：
- `id`：BIGINT，自增主键
- `user_id`：BIGINT，不许空
- `total`：金额，最多 10 位数字（含 2 位小数），不许空，默认 0
- `status`：TINYINT，不许空，默认 0（0 待付 / 1 已付 / 2 已完成）
- `created_at`：日期时间，不许空，默认当前时间

**B2（5 分）** 用**一条语句**插入 3 行：

| user_id | total | status |
|---|---|---|
| 1 | 99.50 | 0 |
| 2 | 200.00 | 1 |
| 1 | 15.00 | 2 |

**B3（5 分）** 把 `status = 0` 的订单改成 `status = 1`。（先 SELECT 确认会改到几行，再改）

**B4（5 分）** 删除 `total < 50` 的订单。（先 SELECT 确认）

## 第二组：查询（35 分）

**B5（5 分）** 查每个员工的姓名、部门名、工资，**按工资从高到低**排序。

**B6（5 分）** 查每个部门的**名称 + 员工数**，**没有员工的部门也要显示（显示 0）**，按人数从高到低、人数相同按 dept_id 升序。

**B7（5 分）** 查工资**高于公司平均工资**的员工姓名、工资（按工资升序）。

**B8（5 分）** 查**部门平均工资高于公司平均工资**的部门名 + 平均工资（保留 2 位小数）。

**B9（5 分）** 查每个员工的**姓名 + 他的上级姓名**（没有上级的也要显示，上级列显示 NULL），按员工 id 升序。

**B10（10 分）** 查**研发部**里工资最高的员工姓名和工资。（要求：用**一条** SQL 完成）

# Part C · 表设计题（25 分）

> 场景：公司要做一个**图书借阅系统**。请设计表结构。

需求：
- 图书（books）：书名、作者、ISBN（唯一）、总册数、可借册数
- 会员（members）：姓名、手机号（唯一）、注册时间
- 借阅记录（borrow_records）：哪本书、哪个会员、借出时间、应还时间、归还时间（未还时为空）、状态（0借出中 / 1已归还 / 2逾期）

**要求**：
1. （10 分）画出三张表的字段清单（字段名 + 类型 + 约束）
2. （10 分）写出三张表的 `CREATE TABLE` SQL（含主键、外键、必要约束）
3. （5 分）说明：这两条查询你会在哪些列上建索引？为什么？
   - ① 查某个会员当前还没还的书
   - ② 查某本书当前被谁借走了
