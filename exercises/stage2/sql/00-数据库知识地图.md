## 五、职业视角：后端工程师"三年内反复用"的 10 件事

1. 写正确的**多表查询**（JOIN + GROUP BY），而不是在 Python 里循环拼数据
2. 按业务需求**设计表**（主外键、约束、范式、命名）
3. 建**合适的索引**，并用 `EXPLAIN` 验证它被用上了
4. 懂**事务**，能避免"扣了钱没加钱"这种事故
5. 会**定位慢查询**（慢查询日志 + EXPLAIN）
6. 知道什么时候**加缓存**（Redis），什么时候不该加
7. 写**参数化查询**，而不是拼字符串（防 SQL 注入）
8. 会**备份/恢复/迁移**数据（`mysqldump`、导入导出）
9. 看得懂 **ORM 生成的 SQL**（阶段 4 会学 SQLAlchemy）
10. 知道 **PG / MySQL 的差异**，能在两者之间迁移

## 六、面试常问 8 题（现在只需"有印象"，不用会答）

> 这 8 题是后端面试的数据库区"必考池"，10-26 周会系统讲。

1. 主键和唯一索引的区别？
2. InnoDB 为什么用 **B+ 树**索引，而不是 B 树 / 哈希？
3. **聚簇索引**和二级索引的区别？**回表**是什么？
4. 事务四大特性（ACID）？四种**隔离级别**分别解决什么问题？
5. **MVCC** 是什么？（一句话：多版本并发控制，让读不加锁）
6. **索引失效**的常见场景有哪些？
7. **深分页**（`LIMIT 100000, 10`）为什么慢？怎么优化？
8. **三范式**是什么？什么时候**反范式**？
