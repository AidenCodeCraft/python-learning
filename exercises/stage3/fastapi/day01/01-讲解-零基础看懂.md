## 0. 一句话

**FastAPI = 让"别人通过网络调用你的 Python 函数"的工具。**
你写的每个被装饰器标记的函数 = 一个**接口（API）**。

---

## 1. 先建立画面：Web API 和你写过的小程序有什么不同

### 你以前写的程序

```text
你在终端敲 python todo.py
  → 程序启动、跑完、退出
  → 只有你自己用，输入输出都在终端
```

### FastAPI 程序

```text
程序**一直运行**，等着别人来"请求"
  → 浏览器 / 前端页面 / Postman / 公司另一个服务 都能调用
  → 输入是 HTTP 请求，输出是 JSON
```

### 一次请求发生了什么

```text
调用方（浏览器/前端/Postman）
   │  ① 发 HTTP 请求：方法 + 路径 +（可能带 JSON 请求体）
   ▼
uvicorn（服务器）：监听 127.0.0.1:8000
   ▼
FastAPI：按"方法 + 路径"去登记表里找 → 找到你写的函数
   ▼
你的函数：拿参数 → 查数据/校验 → return 一个 dict
   ▼
FastAPI：把 dict 变成 JSON，配上状态码
   │  ② 返回响应（状态码 + JSON）
   ▼
调用方拿到 JSON
```

**所以"路由"就是一个门牌号登记表**：
`@app.get("/items")` 意思是 —— "**当有人用 GET 方法访问 /items 时，调用下面这个函数**"。

---

## 2. HTTP 三件套（不懂这三个词，后面全懵）

### ① 方法（Method）：你要干什么

| 方法 | 含义 | 例子 |
|---|---|---|
| `GET` | **查**（不改变数据） | 查商品列表、查某个商品 |
| `POST` | **新建** | 新增一个商品 |
| `PUT` / `PATCH` | **更新** | 改价格 |
| `DELETE` | **删除** | 删商品 |

### ② 路径（Path）+ 查询参数（Query）

```text
http://127.0.0.1:8000/items/5?skip=0&limit=10
└── 协议 ──┘└── 主机 ──┘└端口┘└ 路径 ┘└── 查询参数 ──┘
```

- **路径**：`/items/5` —— 其中 `5` 是**路径参数**
- **查询参数**：`?skip=0&limit=10` —— `?` 后面，用 `&` 分隔
- **请求体（Body）**：POST/PUT 时带的 JSON，不在 URL 里

### ③ 响应：状态码 + body

| 状态码 | 含义 | 什么时候用 |
|---|---|---|
| `200 OK` | 成功 | 查询、更新成功 |
| `201 Created` | 创建成功 | POST 新建后 |
| `204 No Content` | 成功但没有内容 | DELETE 成功（不返回 body） |
| `400 Bad Request` | 你埋的业务错误（可选） | 一般用 422/404 就够 |
| `404 Not Found` | 资源不存在 | 查的 id 不存在 |
| `422 Unprocessable Entity` | **参数校验失败**（FastAPI 默认） | 类型错、`price=-1`、少字段 |
| `500 Internal Server Error` | 服务器代码抛异常 | 你的 bug |

## 3. 逐行拆解最小例子（最重要的一节）

```python
from fastapi import FastAPI          # ① 导入 FastAPI 类

app = FastAPI()                      # ② 创建一个"应用"对象
                                     #    以后所有路由、模型都挂在这个 app 上

@app.get("/")                        # ③ 装饰器：登记"门牌号"
def read_root():                     # ④ 这个函数就是"有人访问 / 时"要执行的代码
    return {"message": "Hello FastAPI"}  # ⑤ 返回 dict → 自动变 JSON，状态码 200
```

### 逐行解释

**① `from fastapi import FastAPI`**
装好包之后，导入框架主类。就像 `import json` 一样，不需要多解释。

**② `app = FastAPI()`**
创建应用对象。`app` 这个名字**随便叫**，但后面启动命令里要用到它（`uvicorn main:app` 里的 `app` 就是它）。
你可以 `app = FastAPI(title="商品 API", version="1.0.0")` —— 这些参数只影响 `/docs` 里显示的信息。

**③ `@app.get("/")` —— 装饰器，你在 D5 补漏包学过**

装饰器 = **不改函数内部，给函数"挂"上额外能力**。
在这里它做的事是：**把"GET 方法 + `/` 路径"和这个函数绑定，登记进路由表**。

```python
# 没有装饰器：函数只是普通函数，没人知道它对应哪个 URL
def read_root(): ...

# 有装饰器：框架启动时会把它登记成 "GET /"
@app.get("/")
def read_root(): ...
```
`@app.post("/items")` 就登记成 "POST /items"。**不同的方法 + 路径 = 不同的接口**。

**④ `def read_root():`**
函数名随意（不影响 URL），但**参数必须和"参数来源"对应**（第 4 节讲）。

**⑤ `return {"message": "Hello FastAPI"}`**
FastAPI 会自动：
1. 把 dict 转成 JSON
2. 设置状态码 200
3. 设置 `Content-Type: application/json`

所以**你只要 return 一个能转成 JSON 的东西**（dict / list / Pydantic 模型 / str / 数字），不用自己拼 JSON。

## 4. uvicorn 是什么？为什么不能直接 `python main.py`

`python main.py` 只会**跑一次脚本然后退出**，它不会监听端口、不会等网络请求。

**uvicorn** 是一个"**服务器**"：它负责监听端口、接收 HTTP 请求、交给 FastAPI 处理、再把结果发回去。

```bash
uvicorn main:app --reload
#       └┬─┘ └┬┘ └──┬──┘
#        模块  变量   开发模式：改代码自动重启
```

- `main` = `main.py` 这个文件（不带 `.py`）
- `app` = 文件里那个 `app = FastAPI()` 变量
- 所以 **`main:app` 的意思 = "main.py 里的 app 对象"**
- 启动后访问 `http://127.0.0.1:8000` 就是你的 API

> 如果 `uvicorn` 命令找不到，用 `.\.venv\Scripts\python.exe -m uvicorn main:app --reload`

## 5. `/docs` 是怎么来的？（FastAPI 最大的爽点）

因为你在函数上写了**类型注解**，FastAPI 自动生成一份 **OpenAPI 文档**：

| 地址 | 是什么 |
|---|---|
| `http://127.0.0.1:8000/docs` | **Swagger UI**：能看到所有接口、能点 `Try it out` 直接调 |
| `http://127.0.0.1:8000/redoc` | ReDoc：更漂亮的纯文档 |
| `http://127.0.0.1:8000/openapi.json` | 原始 OpenAPI JSON |

**这个文档不是手写的** —— 你写了 `item_id: int`、`price: float = Field(gt=0)`，它就自动生成参数说明和校验规则。
**这也是为什么"类型注解在 FastAPI 里不是装饰，是核心功能"。**

## 6. 参数从哪来？（最容易懵的地方）

**记住一条规律**：

| 参数长什么样 | 来源 | 函数里怎么写 |
|---|---|---|
| 在**路径**里：`/items/{item_id}` | 路径参数 | `def get_item(item_id: int)` |
| 不在路径、**有默认值**：`?skip=0&limit=10` | 查询参数 | `def list_items(skip: int = 0, limit: int = 10)` |
| 是 **Pydantic 模型**：POST 的 JSON | 请求体 | `def create_item(payload: ItemCreate)` |

```python
@app.get("/items/{item_id}")          # 路径里有个 {item_id}
def get_item(item_id: int):           # 函数参数名一样 → 框架自动塞进来
    ...
```

**为什么会自动 422？**
因为你写了 `: int`，FastAPI 拿到 URL 里的字符串 `"abc"`，尝试转 int 失败 → 直接返回 422，**你的函数根本不会被调用**（所以不用写 "if not 数字" 的判断）。

## 7. 校验 = Pydantic（"请求体长什么样"的说明书）

用户传上来的数据**不可信**（可能少字段、类型错、负数、超长）。
Pydantic 就是"用类描述数据规则"，FastAPI 拿它自动校验：

```python
from pydantic import BaseModel, Field

class ItemCreate(BaseModel):
    name: str = Field(min_length=1, max_length=50)   # 必须 1~50 个字符
    price: float = Field(gt=0)                        # 必须 > 0
    stock: int = Field(default=0, ge=0)               # 默认 0，且 >= 0
```

规则写在 `Field` 里，FastAPI 自动做三件事：
1. **校验**：不满足 → 422
2. **转换**：`"59.9"` 能转成 `59.9`
3. **写文档**：`/docs` 里显示每个字段的说明和限制

### 真实的 422 长什么样（我跑出来的）

如果你 POST `{"name": "", "price": -1}`，返回 422：

```json
{
  "detail": [
    {"type": "string_too_short", "loc": ["body", "name"],
     "msg": "String should have at least 1 character", "input": ""},
    {"type": "greater_than", "loc": ["body", "price"],
     "msg": "Input should be greater than 0", "input": -1}
  ]
}
```

`loc: ["body", "name"]` = 请求体里的 name 字段；`msg` 就是违反了哪条规则。

### 附件：模型对象的常用方法

| 方法 | 作用 |
|---|---|
| `payload.name` | 取字段 |
| `payload.model_dump()` | 转成 dict |
| `payload.model_dump(exclude_unset=True)` | **只取用户传了的字段**（PUT 局部更新用） |

## 8. `response_model`：返回时的"白名单"

```python
class Item(BaseModel):     # 只写了 4 个字段
    id: int
    name: str
    price: float
    stock: int

@app.get("/items/{item_id}", response_model=Item)
def get_item(item_id: int) -> dict:
    return ITEMS[item_id]   # 这个 dict 里其实还有 secret 字段
```

**结果**：返回的 JSON 里**只有** id/name/price/stock，`secret` 被自动过滤。

**为什么重要**：
- 防止**敏感字段泄露**（密码哈希、内部备注）
- `/docs` 里的响应示例也准确
- 注意：`response_model` 只管"发出去的东西"，不改变你内存/数据库里的数据

## 9. 错误处理：`raise HTTPException` vs `return {"error": ...}`

```python
# ❌ 错误做法：状态码还是 200，调用方会以为成功
return {"error": "Item not found"}

# ✅ 正确做法：状态码 404 + 统一的 detail
raise HTTPException(status_code=404, detail="Item not found")
```

真实返回（我跑出来的）：

```json
HTTP/1.1 404 Not Found
{"detail": "Item not found"}
```

> 公司脚手架通常会在全局把 `detail` 包装成统一格式（`{code, msg, data}`）—— 这就是周五培训要问的问题之一。

## 11. 常见报错对照表

| 现象 | 原因 | 解决 |
|---|---|---|
| `uvicorn : 无法将...识别为 cmdlet` | venv 没激活 / 没用 `python -m` | 用 `.venv\Scripts\python.exe -m uvicorn main:app --reload` |
| `ModuleNotFoundError: No module named 'main'` | 当前目录不是 day01 | `cd` 到 day01 再启动 |
| `[Errno 10048] error while attempting to bind on address` | 8000 端口被占用 | 换端口：`--port 8001` |
| 浏览器打开是 `{"detail":"Not Found"}` | 路径没匹配任何路由 | 检查路径拼写、方法（GET/POST）是否一致 |
| 明明写了接口，`/docs` 里没有 | 装饰器写错 / 函数没定义在 app 上 | 检查 `@app.get(...)` 是否在函数正上方 |
| POST 返回 422 | 请求体不符合模型规则 | 看 422 的 `loc` 和 `msg`，改请求数据或改模型规则 |
| `RuntimeError: Form data requires "python-multipart"` | 用了表单但没装依赖 | 今天不用表单，忽略 |

## 12. 术语表（看一遍，遇到不懂就回来查）

| 术语 | 一句话 |
|---|---|
| API / 接口 | 别人调用你程序的一个"入口" |
| REST | 一种风格：用 GET/POST/PUT/DELETE + 资源路径组织接口 |
| 路由 / 端点（endpoint） | 一个"方法 + 路径"对应一个处理函数 |
| 装饰器 | 给函数挂额外能力的语法（`@xxx`），这里用来登记路由 |
| uvicorn | 运行 FastAPI 的服务器程序（监听端口） |
| ASGI | 异步 Web 应用标准，FastAPI 和 uvicorn 之间的"接口协议" |
| 请求体 / body | POST/PUT 带的 JSON 数据 |
| 路径参数 | URL 路径里的变量，如 `/items/5` 的 5 |
| 查询参数 | `?` 后面的键值对，如 `?skip=0` |
| 状态码 | 200/201/204/404/422/500，表示结果类别 |
| Pydantic | 用类描述数据结构和校验规则的库 |
| 模型（model） | 这里的"模型"= 数据格式类（不是机器学习模型） |
| 422 | FastAPI 的参数校验失败状态码 |
| OpenAPI | 一份描述接口的 JSON 规范，FastAPI 自动生成 |
| Swagger UI | 把 OpenAPI 变成可点击页面的工具（`/docs`） |
| response_model | 响应白名单：只把声明过的字段发出去 |
| HTTPException | 抛出带状态码的错误响应 |
| `--reload` | 开发模式：改代码自动重启 |
| 依赖（dependency） | 接口执行前先准备的东西（明天学 `Depends`） |
| 中间件（middleware） | 每个请求前后都过的"关卡"（明天学） |
