## 第 8 题 · lifespan

**在练什么**：应用启动/关闭钩子。

**从哪开始**：`lifespan` 函数里 **`yield` 前后各写一行**。

```python
@asynccontextmanager
async def lifespan(app: FastAPI):
    # TODO: 启动 → STATE["started"] = True
    yield
    # TODO: 关闭 → STATE["started"] = False
```

**预期**：`GET /lifespan-check` → `{"started": true}`

> ⚠️ 自检脚本用 `with TestClient(app) as client:`，才会触发 lifespan。

## 第 1 题 · 分页依赖（类）

**在练什么**：类作为依赖 + 依赖里的参数校验。

**从哪开始**：`Pagination` 类**已经写好了**（`__init__` 里有 `Query(ge=..., le=...)`），你只改接口：

```python
@app.get("/items", response_model=list[Item])
def list_items(page: Pagination = Depends()) -> list[dict]:
    # 1. 按 id 升序取出：[ITEMS[i] for i in sorted(ITEMS)]
    # 2. 用 page.skip / page.limit 切片
    return []
```

**预期**
| 请求 | 结果 |
|---|---|
| `GET /items` | 2 条 |
| `GET /items?skip=1&limit=1` | 1 条，id=2 |
| `GET /items?limit=0` | **422**（依赖里的 `ge=1` 生效） |
| `GET /items?limit=999` | **422**（`le=100` 生效） |

**常见错误**：
- 接口参数写成 `page: Pagination`（没 `= Depends()`）→ 422（被当成请求体）
- 用 `page[0]`（Pagination 不是序列）→ 用 `page.skip`、`page.limit`

## 第 3 题 · yield 依赖

**在练什么**：资源的打开/关闭 + 响应后清理。

**从哪开始**

```python
def get_db():
    # 进入：STATE["db_opened"] = int(STATE["db_opened"]) + 1
    try:
        yield "session"
    finally:
        # 关闭：STATE["db_closed"] = int(STATE["db_closed"]) + 1
        pass
```

接口：

```python
@app.get("/db-check")
def db_check(db: str = Depends(get_db)) -> dict[str, object]:
    return {"db": db, "opened": STATE["db_opened"]}

@app.get("/db-closed")
def db_closed() -> dict[str, object]:
    return {"closed": STATE["db_closed"]}
```

**预期**
| 请求 | 结果 |
|---|---|
| `GET /db-check` | `{"db": "session", "opened": 1}` |
| `GET /db-closed` | `{"closed": 1}`（说明 yield 之后的清理执行了） |

**常见错误**：
- 没写 `try/finally` → 清理不执行（第 2 个检查会挂）
- `yield` 写在 try 外面 → 同样不清理
- 直接从依赖 `return "session"` → 那就不是 yield 依赖了，第二个检查挂

## 第 4 题 · 中间件：响应头加耗时

**在练什么**：中间件 = 请求/响应都过的关卡。

**从哪开始**（取消注释，补 return）

```python
@app.middleware("http")
async def add_process_time(request: Request, call_next):
    start = time.perf_counter()
    response = await call_next(request)
    # TODO: response.headers["X-Process-Time"] = f"{耗时毫秒:.2f}"
    # TODO: return response
```

**预期**：任意请求的响应头里有 `X-Process-Time`，且值是数字（如 `0.53`）。

**常见错误**：
- 忘了 `await` → 拿到的是协程，`.headers` 报错
- 忘了 `return response` → 接口全部 500
- header 名拼错（自检找的是 `x-process-time`，大小写不敏感）

## 第 5 题 · CORS

**在练什么**：允许指定的前端域名跨域。

**从哪开始**（取消注释）

```python
app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://localhost:3000"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```

**预期**
| 请求 | 结果 |
|---|---|
| `GET /items` 带 `Origin: http://localhost:3000` | 响应头有 `access-control-allow-origin: http://localhost:3000` |
| 带 `Origin: http://evil.com` | **没有**这个头 |

**常见错误**：
- 写成 `allow_origins="http://localhost:3000"`（少了列表）→ 报错
- 用 `["*"]` → 第二个检查（evil.com 应该没有头）会挂

## 第 6/7 题 · 自定义异常 + 全局处理器

**在练什么**：业务代码只管抛，格式由全局处理器统一。

**从哪开始**

```python
# ① 注册处理器（放在 ItemNotFoundError 定义之后）
@app.exception_handler(ItemNotFoundError)
async def item_not_found_handler(request: Request, exc: ItemNotFoundError):
    # return JSONResponse(status_code=404,
    #                     content={"code": 40400, "msg": "Item not found", "data": None})
    ...

# ② 接口里改抛这个异常（不是 HTTPException）
@app.get("/items/{item_id}", response_model=Item)
def get_item(item_id: int) -> dict:
    if item_id not in ITEMS:
        # TODO: raise ItemNotFoundError("Item not found")
        ...
    return ITEMS[item_id]
```

**预期**
| 请求 | 结果 |
|---|---|
| `GET /items/999` | 404 + `{"code": 40400, "msg": "Item not found", "data": null}` |
| `GET /items/1` | 200 + 正常商品 |

**常见错误**：
- 忘注册 handler → 异常冒泡成 500
- handler 里 `return dict` 而不是 `JSONResponse` → 状态码还是 200
- 接口里仍用 `HTTPException` → 返回的是 `{"detail": ...}`，格式对不上
