## 三、逐题批改（30 题）

| 题 | 判定 | 你的问题 | 正确要点 |
|---|---|---|---|
| A1 | 🔶 | tuple 没写"不可变"；`dict[int]` 注解错（要两个类型参数） | list 有序可变 / tuple 不可变 / dict 键值对 / set 去重无序 |
| A2 | ✅ | 输出对、原因对 | 可变默认参数在定义时创建一次、跨调用共享 |
| A3 | ✅ | 浅拷贝例子和解释都对 | `copy()` 只拷外层，内层共享 |
| A4 | ❌ | "两端都输出 True" | 256 → True（小整数缓存）；1000 → False（不同对象）。`is` 比身份、`==` 比值 |
| A5 | 🔶 | 只拆成列表，没转 int；变量名 `str` 遮蔽内置 | `name, age = [x.strip() for x in s.split(",")]; age=int(age)` |
| A6 | 🔶 | `range(1,100)` 漏 100；找到后 `break` 但**没打印** | `for i in range(1,101): if i%7==0: print(i); break` |
| A7 | ❌ | 没掌握 `*args` / `**kwargs`；`print(**dict)` 错 | `def total(*nums): return sum(nums)`；`for k,v in kwargs.items(): print(k,v)` |
| A8 | ✅ | 概念对，还自己验证了会报错 | 赋值才需要 global；读到不需要 |
| A9 | 🔶 | try/except/else/finally 解释略糊；"重试"没实现（除零永远失败，重试无意义） | finally 一定执行；else 仅无异常时执行 |
| A10 | ❌ | **`__int__` 拼错（应为 `__init__`）** → 类根本初始化不了；`__str__` 写死字符串 | `__str__` 要用 `self.name/self.score` |
| A11 | ❌ | `with open(...)` 没用 `as f`；`json.load(path)` 错；`save_config` 缺冒号、没写入文件 | `with open(p, "w", encoding="utf-8") as f: json.dump(data, f, ensure_ascii=False)` |
| A12 | ✅ | 两个都对 | — |
| B1 | 🔶 | 幂等不知道 | GET/PUT/DELETE 幂等；POST 不幂等 |
| B2 | ❌ | 只记得 200 | 9 个状态码见补丁 4 |
| B3 | 🔶 | path/query/body 基本对；Authorization 不清楚 | header 用 `Header()` 或安全依赖取 |
| B4 | ✅ | 对（后者是 `\u` 转义，不是"乱码"但意思对） | `ensure_ascii=False` 保留中文 |
| B5 | 🔶 | 阻塞解释大致对；异步解释反了 | 异步 = 等待时不占线程，去处理别的请求 |
| B6 | ❌ | 不知道 | 同源策略；服务端 `CORSMiddleware` 放行 |
| C1 | ❌ | 顺序错（SELECT 不能第一） | FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY → LIMIT |
| C2 | ❌ | 记不全了 | 不能；跳过最左列。改成 `status=1 AND score>60` |
| C3 | ❌ | 只记得 A | A→undo、C→应用+约束、I→MVCC+锁、D→redo |
| C4 | ✅ | 对 | COUNT(*) 算 NULL 行=1；COUNT(id)=0 |
| D1 | 🔶 | body 说错（"用 http:// 就是请求体"） | 路径里 `{}`→路径参数；有默认值→查询参数；Pydantic 模型→请求体 |
| D2 | 🔶 | `le=100` 说成"大于等于" | `le` = 小于等于（≤） |
| D3 | ✅ | 对 | 按响应模型序列化，未声明字段被丢弃 |
| D4 | 🔶 | Depends 作用对；与装饰器区别不清楚 | 装饰器处理"整个函数"；依赖准备"参数" |
| D5 | ❌ | 不知道 | lifespan：启动/关闭钩子，连接池放这里 |
| E1 | ❌ | 不知道 | `git checkout -b feature/x` → add/commit → push -u → PR |
| E2 | ❌ | 不知道 | `def test_add(): assert add(1,2)==3` |
| E3 | 🔶 | 意思沾边 | 放环境变量/`.env`（不进 git），`os.getenv` 或 pydantic-settings 读 |
