## Part A · Python

**A1** 补丁 1
- list：有序、可变、可重复 `[]`
- tuple：有序、**不可变** `()`
- dict：键值对、键唯一 `{}`
- set：**无序、去重** `set()`
- 常见错误：说"tuple 更快"却说不出为什么（不可变、可哈希）

**A2** 补丁 2（默认参数陷阱）
- 输出：`[1]` 再 `[1, 1]` —— 默认参数 `x=[]` **只在函数定义时创建一次**，被跨调用共享
- 正确写法：`def f(x=None): x = x or []`
- 这题考的是"可变默认参数"，面试常问

**A3** 补丁 3（浅拷贝）
- `a["tags"]` 变成 `["a", "b", "c"]` —— `copy()` 是**浅拷贝**，内层 list 还是同一个对象
- 深拷贝：`copy.deepcopy(a)` 才互不影响
- 常见错误：以为 `copy()` 完全独立

**A4** 补丁 4（`is` vs `==`）
- `256` → `True`；`1000` → `False`（交互式环境/模块里可能 `True`，取决于是否命中缓存）
- `is` 比较**对象身份**（内存地址），`==` 比较**值**
- 小整数 -5~256 被缓存 → 同一对象
- 规则：**判断 None 用 `is None`，比较值用 `==`**

**A8** 补丁 8（作用域）
- 函数里给变量**赋值**时，Python 默认它叫局部变量；不加 `global` 就会创建新的局部变量，外面的不变
- 不加 `global` 读全局变量没问题，**写**才需要

**A9** 补丁 9
- `try` 正常执行；出错 → `except`；`try` 无异常 → `else`；**无论如何最后都执行 `finally`**
```python
def div_retry(a: int, b: int, times: int = 3) -> float:
    for _ in range(times):
        try:
            return a / b
        except ZeroDivisionError:
            print("除零，重试")
    raise ValueError("重试次数用完")
```

## Part B · Web/HTTP

**B1** 补丁 13：GET 查（幂等/安全）、POST 新建（不幂等）、PUT 更新/替换（幂等）、DELETE 删除（幂等）

**B2** 补丁 14：200 成功 / 201 创建成功 / 204 成功无内容 / 400 请求参数有误（业务） / 401 未认证 / 403 无权限 / 404 不存在 / 422 校验失败 / 500 服务器错误

**B3** 补丁 15：
- `5` → 路径参数 `item_id: int`（装饰器里 `/items/{item_id}`）
- `limit` → 查询参数 `limit: int = 10`
- `Authorization` → header：`authorization: str | None = Header(default=None)`（或安全依赖）
- body → Pydantic 模型参数

**B4** 补丁 16：
- `ensure_ascii=False` → `{"name": "张三"}`
- 默认 → `{"name": "\u5f20\u4e09"}`（能还原，但不可读、占空间）

**B5** 补丁 17：阻塞 = 等待期间线程/事件循环干不了别的（如 `time.sleep`、同步 DB 查询）。FastAPI 是异步框架，`async def` 里做同步阻塞操作会**卡住整个事件循环**，所以要 `await` 异步库。

**B6** 补丁 18：浏览器同源策略 —— 页面（`:3000`）和接口（`:8000`）不同源。服务端返回 CORS 响应头（`CORSMiddleware` 配置 `allow_origins`）放行。

## Part C · 数据库

**C1**：FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY → LIMIT
（注意：`WHERE` 在聚合前、`HAVING` 在聚合后；`SELECT` 里的别名不能给 `WHERE` 用）

**C2**：**不能**。联合索引只能从最左列 `status` 开始用；`WHERE score > 60` 跳过了 `status`。
能用上的写法：`WHERE status = 1 AND score > 60`（等值列在前，范围列在后）。

**C3**：A 原子性 → undo log；C 一致性 → 应用 + 约束；I 隔离性 → MVCC + 锁；D 持久性 → redo log。

**C4**：`COUNT(*)` = **1**（把没匹配的 NULL 行也算一条）；`COUNT(employees.id)` = **0**（NULL 不计数）。所以统计左连接结果要用 `COUNT(右表.id)`。

## Part D · FastAPI

**D1**：出现在路径里 `{item_id}` → 路径参数；有默认值且不在路径 → 查询参数；类型是 Pydantic 模型 → 请求体。

**D2**：`gt=0` 大于 0；`ge=0` 大于等于 0；`min_length=1` 字符串至少 1 字符；`le=100` 小于等于 100。

**D3**：`response_model` 声明响应结构，FastAPI 按模型**序列化过滤**未声明字段（如 `secret`），同时让 `/docs` 文档准确。

**D4**：`Depends(f)` = 执行接口前先调用 `f()`，把返回值注入参数（取分页/配置/数据库会话/当前用户）。
装饰器处理**整个函数**（登记路由、包能力）；依赖处理**参数**。

**D5**：`lifespan` = 应用启动/关闭钩子（yield 前启动、后关闭）。连接池/Redis 客户端只建一次、全局复用，避免每请求新建导致性能与连接数问题。
