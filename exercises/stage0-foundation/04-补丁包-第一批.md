# P0-1 · 类（30 分钟）

**一句话**：类是"数据 + 操作数据的函数"的打包；`__init__` 是"创建对象时自动执行的方法"。

```python
class Student:
    def __init__(self, name: str, score: int) -> None:   # ❗是 __init__ 不是 __int__
        self.name = name                                  # self = 这个对象自己
        self.score = score

    def is_pass(self) -> bool:
        return self.score >= 60                           # 方法里用 self.xxx

    def __str__(self) -> str:                             # print(对象) 时调用
        return f"{self.name}: {self.score}"               # ❗要用 self，不能写死


s = Student("张三", 85)
print(s)            # 张三: 85
print(s.is_pass())  # True
```

### 你在诊断卷犯的错

```python
# ❌ 你写的
def __int__(self, name, score):     # 拼错 → 对象没有 name/score → 后面全崩
def __str__(self) -> str:
    return "张三：85"                # 写死，换个学生就错了
```

### 三个必背点

1. `__init__`（两个下划线 + init，**没有 i 后面的 t**）
2. 方法第一个参数永远是 `self`，里面用 `self.属性`
3. 双下划线方法：`__init__` 创建时、`__str__` print 时、`__repr__` 调试时

### 默写题

> 写一个 `Order` 类：`__init__(order_id, amount)`；方法 `is_expensive()` 返回 amount > 100；`__str__` 返回 `"订单1: 199元"`。

# P0-2 · 文件 + JSON（30 分钟）

**一句话**：`with open(...) as f` 打开文件、自动关闭；JSON 用 `json.load(f)` 读、`json.dump(data, f)` 写。

```python
import json
from pathlib import Path


def load_config(path: Path) -> dict:
    """读 JSON；文件不存在或格式错都返回 {}。"""
    if not path.exists():
        return {}
    try:
        with open(path, "r", encoding="utf-8") as f:     # ❗必须有 as f
            return json.load(f)                          # ❗load 收文件对象，不是路径
    except json.JSONDecodeError:
        return {}


def save_config(path: Path, data: dict) -> None:
    with open(path, "w", encoding="utf-8") as f:         # ❗w = 覆盖写
        json.dump(data, f, ensure_ascii=False, indent=2) # ❗dump 要写进 f
```

### 你在诊断卷犯的错

```python
with open(path, "r", encoding="utf-8"):     # ❌ 没 as f
    return json.load(path)                  # ❌ load 收到了路径
json.dumps(data)                            # ❌ dumps 只返回字符串，没写文件
```

### 必背对照

| 函数 | 用途 |
|---|---|
| `json.load(f)` | 从**文件对象**读成 dict |
| `json.loads(s)` | 从**字符串**读成 dict |
| `json.dump(data, f)` | dict **写进文件** |
| `json.dumps(data)` | dict **转成字符串** |

### 默写题

> 写 `save_students(path, students)`：把学生列表写进 JSON，中文不转义；再写 `load_students(path)`，文件不存在返回 `[]`。

# P0-3 · `*args` / `**kwargs`（20 分钟）

**一句话**：`*args` 收"任意多个位置参数"成 tuple；`**kwargs` 收"任意多个关键字参数"成 dict。

```python
def total(*nums: float) -> float:        # total(1, 2, 3) → nums = (1, 2, 3)
    return sum(nums)


def show(**kwargs: object) -> None:      # show(name="张三", age=20) → kwargs = {"name": "张三", "age": 20}
    for key, value in kwargs.items():
        print(f"{key} = {value}")
```

### 你在诊断卷犯的错

```python
def total(number: list[int]) -> int:     # ❌ 不是 *args，调用方要传列表
def show(number: dict) -> None:
    print(**number)                      # ❌ print(**{"a":1}) 会变成 print(a=1) → 报错
```

### 记忆

- `*` = 打包成 **tuple**（位置参数）
- `**` = 打包成 **dict**（关键字参数）
- 用在 FastAPI 里：`**payload.model_dump()` 就是解包

### 默写题

> 写 `def build_url(base, *paths, **query)`：返回 `base/path1/path2?k1=v1&k2=v2`。

# P0-4 · 状态码 9 个（20 分钟）

| 码 | 含义 | 什么时候用 |
|---|---|---|
| 200 | OK | 查询/更新成功 |
| 201 | Created | POST 创建成功 |
| 204 | No Content | DELETE 成功（无 body） |
| 400 | Bad Request | 请求参数业务上不合法（如"不允许改的字段"） |
| 401 | Unauthorized | **没登录/没带 token** |
| 403 | Forbidden | 登录了但**没权限** |
| 404 | Not Found | 资源不存在 |
| 422 | Unprocessable Entity | **参数校验失败**（FastAPI 默认） |
| 500 | Internal Server Error | 服务器代码崩了 |

**记忆法**：
- 2xx 成功（200 查、201 建、204 删）
- 4xx 是**调用方**的问题（400 参数、401 身份、403 权限、404 找不到、422 校验）
- 5xx 是**服务器**的问题

**401 vs 403**：401 = "你是谁？"（没认证）；403 = "我知道你是谁，但你不能干这个"。

### 默写题

> 不看上面，写出 9 个状态码和一句话含义。

# P1-1 · 参数来源 + 幂等（30 分钟）

**判断规律（背下来）**：

| 参数在哪 | FastAPI 里怎么写 |
|---|---|
| 路径里 `/items/{item_id}` | `def get_item(item_id: int)` |
| 不在路径、**有默认值** `?limit=10` | `def list_items(limit: int = 10)` |
| 是 **Pydantic 模型**（POST/PUT 的 JSON） | `def create(payload: ItemCreate)` |
| 请求头 `Authorization: Bearer xxx` | `authorization: str \| None = Header(default=None)` |

**幂等**：同一个请求执行 1 次和执行 N 次，结果一样。

| 方法 | 幂等？ |
|---|---|
| GET | ✅ |
| PUT | ✅（整体替换，重复执行结果相同） |
| DELETE | ✅（删两次还是"删掉了"） |
| POST | ❌（创建两次会生成两条） |

### 默写题

> `POST /students?notify=true`，body `{"name":"张三"}`，header `X-Token: abc`。写出函数签名（5 行以内）。

# P1-2 · Depends vs 装饰器 + lifespan（30 分钟，复习）

### Depends

```python
def get_settings() -> dict[str, str]:
    return {"app_name": "商品 API", "version": "2.0.0"}

@app.get("/info")
def get_info(settings: dict[str, str] = Depends(get_settings)):
    return settings          # ❗要真的用它，不能绕过
```

**一句话**：接口执行前，框架先调用依赖函数，把返回值塞进参数。

### 和装饰器的区别（必背）

| | 装饰器 `@app.get(...)` | 依赖 `Depends(...)` |
|---|---|---|
| 作用对象 | **整个函数**（登记路由、加能力） | **某个参数**（准备值） |
| 例子 | `@app.get("/items")` | `page: Pagination = Depends()` |

### lifespan

```python
@asynccontextmanager
async def lifespan(app: FastAPI):
    app.state.redis = aioredis.from_url(...)   # 启动时：建连接池
    try:
        yield
    finally:
        await app.state.redis.aclose()         # 关闭时：释放
```

**为什么放这里**：连接池/Redis 客户端只建一次全局复用；每个请求新建会很慢、连接数爆炸。

### 默写题

> ① 写出 `Depends` 注入配置依赖的接口 ② 说出 lifespan 的 yield 前后各做什么。

# P1-3 · SQL 复习（40 分钟）

### 1. SELECT 逻辑执行顺序（必背）

```text
FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY → LIMIT
```

- `WHERE` 在聚合**前**（过滤行）
- `HAVING` 在聚合**后**（过滤组）
- `SELECT` 里的别名**不能给 WHERE 用**（WHERE 时期别名还不存在）

### 2. 最左前缀

索引 `(status, score)`：

| 条件 | 能用索引？ |
|---|---|
| `WHERE status = 1` | ✅ |
| `WHERE status = 1 AND score > 60` | ✅ |
| `WHERE score > 60` | ❌（跳过最左列） |

### 3. ACID 与实现

| 特性 | 靠什么 |
|---|---|
| A 原子性 | **undo log** |
| C 一致性 | **应用 + 约束** |
| I 隔离性 | **MVCC + 锁** |
| D 持久性 | **redo log** |

### 默写题

> ① 默写 SELECT 执行顺序 ② 联合索引 `(a,b)` 哪些条件用得上 ③ ACID 四句。
