## 使用方法

1. **今天先做诊断卷**（闭卷、40 分钟，写不出就写"不会"）
2. 自评：✅ 会 / 🔶 半会 / ❌ 不会
3. 把自评表 + ❌ 题号发教练
4. 教练按缺口排补丁顺序（只补缺的），每天 60 分钟补 1~2 个
5. 每个补丁学完 → 立刻做一张**默写卡**（见 [notes/12](../../notes/12-每日训练SOP-闭卷默写与间隔复习.md)）
