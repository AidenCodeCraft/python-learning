## 功能 A（简单）· 给 `count_words` 加"最短词长"参数

```python
def count_words(text: str, min_length: int = 1) -> dict[str, int]:
    """统计每个词出现的次数；长度小于 min_length 的词不计入。"""
```

要求：
- 默认 `min_length=1` → **行为必须和改造前完全一致**（先验证这一点，这叫"不破坏旧功能"）
- `min_length=3` 时，长度 < 3 的词（如 `a`、`an`、`on`、`is`、`by`）不计入

**验证**：`python my_word_counter.py reference\sample.txt` 输出必须和 ②抄 时**一模一样**（22 个不同词）。

---

## 功能 B（中等）· 加命令行参数 `--min-length N`

```powershell
python my_word_counter.py reference\sample.txt --min-length 3
```

要求：
- 不传时默认 1
- 传了要能正确转成 `int`
- 参数写错（比如 `--min-length abc`）程序不能崩，要提示

**验证预期（已实测）**：

| 命令 | 预期输出 |
|---|---|
| `--min-length 3` | `不同单词数: 18`，Top5 仍是 `the 12 / cat 5 / dog 4 / and 3 / sea 3` |
| `--min-length 5` | `不同单词数: 6`，Top5 是 `shells 3 / knows 2 / sells 2 / friends 1 / nobody 1` |

## 功能 C（难）· 加一行汇总统计

要求程序最后多打印一行：

```text
原文共 53 个词，符合条件的不同词 22 个
```

- `53` = **原文总词数**（不受 `--min-length` 影响）
- `22` = 过滤后统计到的**不同词数**

`--min-length 3` 时应该是：

```text
原文共 53 个词，符合条件的不同词 18 个
```

**这一问的关键**：`count_words` 现在只返回 dict，拿不到"原文总词数"。
你有两种做法（都要想清楚再选）：

1. 在 `main` 里自己再数一遍 `len(text.split())`
2. 把 `count_words` 的返回值改成 `(counts, total)`

> 选哪个都行，但要在注释里写一句"为什么选这个"。
> **这是这一段最重要的一种思考：改一个函数，要不要动它的接口。**
