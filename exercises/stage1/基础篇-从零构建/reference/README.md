# 本目录文件角色（很容易搞混，动手前先看这里）

| 文件 | 谁写的 | 用途 | 能不能改 |
|---|---|---|---|
| `word_counter.py` | **教练** | ①读 / ②抄 的**参考实现** | ❌ **绝对不要改**（改了就没有参照物了） |
| `sample.txt` | 教练 | 示例数据 | ❌ 不要改 |
| `my_word_counter_annotated.py` | 你 | ①读 的**逐行注释版** | ✅ 你的作业，可以改 |
| `my_word_counter.py` | 你 | ②抄 的**手抄版**；③改 也在这个文件上改 | ✅ 你的作业，可以改 |

## ⚠️ 2026-10-22 踩过的坑

参考实现 `word_counter.py` 被误改成 `key=lambda kv: (kv[-1], kv[0])`（升序），
导致输出从 `the 12` 变成 `bird 1` —— **参考实现被污染，后面的对照全部失真**。

**规则**：
1. 改代码前先看**文件名**（两个文件只差 `my_` 前缀和 `_annotated`）。
2. ③改 的所有改动**只改 `my_word_counter.py`**。
3. 改完**立刻跑三个命令**，输出必须和这里的预期一致：

```text
python word_counter.py sample.txt --top 5
→ 不同单词数: 22；the 12 / cat 5 / dog 4 / and 3 / sea 3
```
