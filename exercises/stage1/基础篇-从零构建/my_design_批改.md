## 需求 1 · 单词计数器（60）

### ✅ 对的
- 数据用 `dict[str, int]`，举例 `{"a":10,"b":9}` —— 结构选对了。
- 模块拆成"读文件 / 统计 / 排序打印" —— 分工方向对。
- 第 1 步想到 `try/except FileNotFoundError` —— 错误处理意识到位。

### ❌ 三处问题

**问题 1（概念错）：第 2 步 `json.load()`**
单词计数器读的是**普通文本文件**（`.txt`），里面是 `The cat sat...`，**不是 JSON**。
`json.load()` 会直接报 `JSONDecodeError`。
→ 正确做法：`open(path, encoding="utf-8").read()`（就是 D3 微课学的文件读写）。

**问题 2（概念错）：第 3/4 步把"单词"写成了"字母"**
"统计字母出现次数"和"统计单词出现次数"是两个不同的程序。
而且你漏了两个关键动作：**`split()` 切词**、**`strip(标点)` 去首尾标点**（否则 `cat,` 和 `cat` 会被算成两个词）。

**问题 3（结构缺）**
- ② 里"排序函数并打印前 10"把两件事绑在一起 → 排序函数**只排序、不打印**，打印归 `main`。
- 没写我要求的"**谁不许干什么**"（例如：读文件函数不许打印、不许排序）。

### ✏️ 参照这个写法改（示范版）

```markdown
## 需求 1：单词计数器

### ① 数据长什么样
统计结果：dict[str, int]，例如 {"the": 12, "cat": 5}

### ② 分几个部分？各自职责一句话
- read_text(path) -> str     只负责读文件内容；文件不存在返回 ""；**不许打印**
- count_words(text) -> dict  只负责切词+去标点+小写+计数；**不读文件、不打印**
- top_n(counts, n) -> list   只负责按次数排序取前 n；**不打印**
- main(argv)                 只负责解析参数、串联上面三步、打印

### ③ 分几步做（伪代码）
1. 从 argv 拿文件路径和 --top N（默认 10）
2. read_text 读文本；为空 → 打印提示、返回 1
3. count_words：text.split() 切词 → 每个词 strip 标点 + lower() → 跳过空串 → dict 计数
4. top_n：按 (-次数, 单词) 排序 → 取前 N
5. 打印结果
```

## 需求 3 · 简易 ATM（65）

### ✅ 最好的一点
第 3 步："取款失败返回 `False`，因为超出余额**不属于异常**，代码不会报错" ——
**这个判断完全正确**，说明你在想"错误该用什么方式表达"。

### ❌ 两处问题

**问题 1：② 只有 I/O 函数，缺业务函数**
现在只有 `load_json()` / `write_json()`，但 ATM 的核心逻辑（存钱、取钱、查余额）一个都没写。
→ 至少要有：`deposit(amount)` / `withdraw(amount)` / `get_balance()`，它们内部再调读写函数。

**问题 2：漏了输入校验**
- "金额必须正数"（存 -100 会怎样？）
- 取款成功后**要写回文件**（漏了这一步，重启数据就丢了）

### ✏️ 补法（不给全答案，自己写完这三行）
```text
- 模块：load() / save() / deposit(amount) -> bool / withdraw(amount) -> bool / get_balance() -> int
- 校验：amount <= 0 → 返回 False；withdraw 超额 → 返回 False
- 每次成功修改后 → save()
```
