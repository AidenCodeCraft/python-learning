## 需求：书签管理器（bookmark CLI）

### 功能

| 命令 | 行为 |
|---|---|
| `add <标题> <网址> [--tags a,b]` | 新增一条书签，id 从 1 自增 |
| `list [--tag 标签]` | 列出书签（默认全部；带 `--tag` 只显示含该标签的） |
| `search <关键词>` | 在标题里模糊搜索 |
| `delete <id>` | 删除一条 |
| `stats` | 打印：总数、标签个数、每个标签各有多少条 |

### 数据

- 存 JSON 文件（默认 `.tmp/bookmarks.json`），**重启程序后数据还在**
- 每条长这样：

```json
{"id": 1, "title": "Python 官方文档", "url": "https://docs.python.org", "tags": ["python", "doc"]}
```

### 要求

1. **先写设计卡**（三段设计法，见 [00-方法-三段设计法.md](00-方法-三段设计法.md)），设计卡让教练看过再写代码。
2. **至少分 2 个文件**：
   - `bookmarks.py`：数据 + 逻辑（**不许 print、不许碰 sys.argv**）
   - `cli.py`：参数解析 + 调用 + 打印
3. 代码 **100~150 行**（有效行），**类型注解完整**，**没有裸 `except:`**。
4. **自己验证 3 个场景**（把输出贴给教练）：
   - 添加 3 条 → `list` 显示 3 条
   - 删除 1 条 → `list` 剩 2 条；`delete 999` 不崩、给提示
   - 关掉程序重新运行 → 数据还在（持久化真的生效）
5. 出错处理：文件不存在 → 当成空列表；网址不合法（不以 `http` 开头）→ 提示并拒绝。

## 卡住时的 5 级提示（按顺序，别跳）

1. **思路**：先问自己"这条命令要走哪几步？读文件 → 改数据 → 写文件 → 打印"。
2. **伪代码**：把 `cli.py` 的 `main` 写成 5 行伪代码（每个命令一个分支）。
3. **关键 API**：`json.dump/load`（D4 微课）、`path.exists()`、`sys.argv` 切片、`sorted(key=lambda)`（D4 要点 12）。
4. **局部代码**：先只实现 `add` + `list`，跑通了再加 `search` / `delete` / `stats`。
