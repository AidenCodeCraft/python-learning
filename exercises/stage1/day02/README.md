## 二、讲解 + 示例（25 分钟）

### 要点 1：算术运算符 `/ // % **`

| 写法 | 名字 | 例子 | 结果 | 一句话 |
|---|---|---|---|---|
| `/` | 真除法 | `7 / 2` | `3.5` | **结果永远是 `float`**（`6 / 2` 也是 `3.0`） |
| `//` | 整除（向下取整） | `7 // 2` | `3` | 向**负无穷**取整，不是向零 |
| `%` | 取余 | `7 % 3` | `1` | 结果符号**跟除数走** |
| `**` | 幂 | `2 ** 10` | `1024` | 也可以用 `pow()` |

三条最容易踩的：

```python
-7 // 2      # -4   ← 不是 -3！因为 -3.5 向下取整是 -4
7 // -2      # -4   ← 除数是负数，一样向下取整
-7 % 3       # 2    ← 符号跟除数（3 是正数）；不要用 C 的直觉
```

> **记忆法**：任何情况下都满足 `a == (a // b) * b + (a % b)`。
> 拿 `a = -7, b = 2` 验：`(-7 // 2) = -4`、`(-7 % 2) = 1` → `-4 * 2 + 1 = -7` ✅
> 再拿 `a = -7, b = 3` 验：`(-7 // 3) = -3`、`(-7 % 3) = 2` → `-3 * 3 + 2 = -7` ✅
> 看出来了：**不管除数是正还是负，`//` 都往负无穷方向取整；`%` 的符号跟着除数走。**
> 动手把这四组（`-7 // 2`、`7 // -2`、`-7 % 3`、`7 % -3`）都跑一遍，比我讲十遍有用。

### 要点 2：比较运算符 + 链式比较

`== != > < >= <=` 结果都是 `bool`。

Python 特有：**链式比较**，可以直接连写。

```python
1 < 5 < 3        # False，等价于 (1 < 5) and (5 < 3)
0 <= score <= 100    # 判断分数在 0~100 之间，比 and 更清爽
```

> 注意：`==` 比**内容**，`is` 比**身份**（D1 学过）。判断"是不是 None"用 `is None`，不要用 `== None`。

### 要点 3：`and` / `or` 返回的是**操作数本身**

这是今天最容易错的一点。Python 的 `and` / `or` **不返回 `True/False`**，而是返回"决定结果的那个操作数"：

| 表达式 | 结果 | 为什么 |
|---|---|---|
| `0 or "默认"` | `"默认"` | `0` 是假 → 看右边，返回右边 |
| `"a" and "b"` | `"b"` | `"a"` 是真 → 看右边，返回右边 |
| `"" or 0 or [] or "最后"` | `"最后"` | 从左到右，返回第一个真值 |
| `"a" and ""` | `""` | 左边真 → 返回右边（哪怕是假值） |

**实战用法**：给变量设默认值。

```python
name = user_input or "匿名"      # 输入为空 → 用 "匿名"
```

### 要点 4：短路求值

- `and`：左边为假，**右边根本不执行**。
- `or`：左边为真，**右边根本不执行**。

```python
def boom() -> str:
    print("被执行了")
    return "boom"

False and boom()    # False      —— boom() 没被执行
True or boom()      # True       —— boom() 没被执行
True and boom()     # 打印"被执行了"，返回 "boom"
```

**实战用法**：把"贵的判断"放后面 / 用 `or` 兜底。

```python
if user and user.name:      # user 为 None 时，不会去访问 user.name（不会报 AttributeError）
    ...
```

### 要点 5：成员运算符 `in` / `not in`

| 场景 | 例子 | 结果 |
|---|---|---|
| 子串 | `"bc" in "abcd"` | `True` |
| 列表元素 | `2 in [1, 2, 3]` | `True` |
| **字典判 key** | `"id" in {"id": 1}` | `True` |
| 字典**不判 value** | `1 in {"id": 1}` | `False` |

> 字典的 `in` 只看 **key**，这是新手最容易记错的一条。

### 要点 6：真值判断与假值清单（必须背下来）

**假值只有这几个**（其余全为真）：

```text
False   None   0   0.0   ""   []   ()   {}   set()
```

```python
if items:            # 等价于 if len(items) > 0
    ...
if not name:         # 等价于 if name == "" or name is None
    ...
```

注意两个反直觉的：`bool("0")` 是 **`True`**（非空字符串），`bool([0])` 也是 **`True`**（非空列表）。

### 要点 7：`if` / `elif` / `else` 与三元表达式

```python
if score >= 90:
    grade = "A"
elif score >= 80:        # elif = "否则如果"
    grade = "B"
else:
    grade = "F"
```

两条铁律：

1. **命中即停**：一旦某个分支成立，后面的 `elif` / `else` 都不再看。
2. **顺序重要**：范围小的条件要写在前面。FizzBuzz 里必须先判"同时是 3 和 5 的倍数"，否则永远轮不到 `FizzBuzz`。

三元表达式（一行写完简单分支）：

```python
label = "奇数" if n % 2 else "偶数"
```

### 要点 8：浮点陷阱（认知即可）

```python
0.1 + 0.2            # 0.30000000000000004
0.1 + 0.2 == 0.3     # False   ← 所以永远不要用 == 比浮点数
```

要比较时用 `abs(a - b) < 1e-9`（阶段 2 起处理金额会再讲）。
