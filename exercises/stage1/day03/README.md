## 二、讲解 + 示例（40 分钟）

### 要点 1：`for` 的本质是"遍历"，不是"计数"

```python
for t in ["a", "b", "c"]:     # t 依次取到每个元素
    print(t)
```

`for` 右边可以是任何**可迭代对象**：列表、字符串、字典、`range`、文件对象……
不要想成 C 的 `for (i = 0; i < n; i++)` —— Python 的 `for` 是"**把里面的东西一个个拿出来**"。

### 要点 2：`range` 三兄弟（**`stop` 是开区间**）

| 写法 | 含义 | 例子 | 结果 |
|---|---|---|---|
| `range(5)` | 0 到 4 | `list(range(5))` | `[0, 1, 2, 3, 4]` |
| `range(2, 10, 3)` | 从 2 开始，每次 +3，到 10 之前 | `list(range(2, 10, 3))` | `[2, 5, 8]` |
| `range(10, 0, -2)` | 步长为负 → 倒着来 | `list(range(10, 0, -2))` | `[10, 8, 6, 4, 2]` |
| `range(5, 0)` | 方向反了 → 空 | `list(range(5, 0))` | `[]` |

**三条规则**：
1. `stop` **取不到**（开区间）→ 想要 1~100 就写 `range(1, 101)`。
2. 步长为负时必须 `start > stop`，否则空。
3. `range` 本身**不是列表**，`print(range(5))` 打印的是 `range(0, 5)`；要看内容得 `list(...)`。

### 要点 3：`while` —— 只要条件为真就一直转

```python
total = 0
i = 1
while i <= 5:      # ① 条件
    total += i     # ② 干活
    i += 1         # ③ 让条件变量前进 ← 忘了这行 = 死循环
print(total, i)    # 15 6
```

**`while` 的三件套**：初始化 → 条件 → 让变量前进。
**自查口诀**：写完 `while` 先问自己一句 —— **"哪个变量在前进？它最终会让条件变假吗？"**

> ⚠️ 死循环不可怕，`Ctrl + C` 能停；可怕的是**看不出来**。今天的 `ex07` 就是一道"看不出死循环"的改错题。

### 要点 4：`for` 还是 `while`？

| 用 `for` | 用 `while` |
|---|---|
| 知道要遍历什么（列表/字符串/range） | 不知道要转几次，只看条件（如"猜数字直到猜对"） |
| 99% 的日常场景 | 少用，且**必须**有前进语句 |

> 经验：**能用 `for` 就别用 `while`** —— `for` 天然不会死循环。

### 要点 5：`break` 和 `continue`

```python
for n in range(1, 10):
    if n == 4:
        break          # 整个循环**立刻结束**
    print(n)           # 1 2 3

for n in range(1, 8):
    if n % 2 == 0:
        continue       # 只跳过**本次**，继续下一轮
    print(n)           # 1 3 5 7
```

记忆：**`break` 是"不干了"，`continue` 是"这个不要，下一个"。**

### 要点 6：`for ... else`（Python 特色，容易看错）

```python
for n in [1, 3, 5]:
    if n == 4:
        break
else:
    print("没找到 4")     # ← 循环**没有被 break 打断** 时才执行
```

**`else` 挂在 `for` 上，不是挂在 `if` 上。** 用途：搜索失败时给提示，替代"设一个 flag 变量"。

### 要点 7：`enumerate` 和 `zip`

```python
tasks = ["写代码", "自测", "提交"]
for i, t in enumerate(tasks):        # 下标默认从 0
    print(i, t)
for i, t in enumerate(tasks, 1):     # 也可以从 1 开始
    print(i, t)
```

```python
names = ["Tom", "Ann", "Bob"]
scores = [90, 85]
print(list(zip(names, scores)))      # [('Tom', 90), ('Ann', 85)]  ← 以短的为准
```

**`enumerate` 替代 `for i in range(len(x))`** —— 后者是 C 思维，Python 里要改掉。

### 要点 8：嵌套循环（外圈 1 次 = 内圈跑满 1 轮）

```python
for i in range(1, 3):
    for j in range(1, 3):
        print(i, j)     # 1 1 / 1 2 / 2 1 / 2 2
```

### 要点 9：循环变量的两个"冷知识"

```python
count = 0
for i in range(5):
    count += i
print(count, i)      # 10 4  ← i 出了循环还在！(Python 不隔离循环变量)
```

```python
user = {"id": 1, "name": "Tom"}
for k in user:               # 遍历字典默认给 key
    print(k)
for k, v in user.items():    # 要 key+value 用 .items()
    print(k, v)
```
