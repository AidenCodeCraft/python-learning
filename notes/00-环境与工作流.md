## 三、踩过的两个坑（记下来，以后不重复踩）

### 坑 1：工作区被 Windows 文件权限挡住

**现象**：AI 在工作区执行任何命令都报 `grantWrite(G:\python-learning)`。

**原因**：`G:\python-learning` 是当前用户所有，但缺少 `WRITE_OWNER`，沙箱无法发放写权限。

**处理**：用官方诊断脚本修了一次（只补了当前用户的一条完全控制权限项，未改文件内容、未改所有者）。
备份与回滚脚本在 `G:\dsh-acl-report\`。

### 坑 2：PowerShell 脚本中文乱码导致解析失败

**现象**：`.\setup_env.ps1` 报一堆"表达式或语句中包含意外的标记"。

**原因**：Windows PowerShell 5.1（`powershell.exe`）默认按 **GBK** 读取 `.ps1`。
脚本文件是无 BOM 的 UTF-8，中文被读成 `鍗囩骇澶辫触`，把字符串引号撑坏了。

**处理**：给 `.ps1` 文件加 **UTF-8 BOM**。

**经验**：以后在这个仓库里写的所有 `.ps1` 都要带 BOM（`.gitattributes` 已固定 `*.ps1` 用 CRLF）。
`.py` 和 `.md` 用 UTF-8 无 BOM 没问题。

## 六、`uv` 快速上手（阶段 3 起正式用）

| 你想做的事 | venv + pip | uv |
| --- | --- | --- |
| 建环境 | `python -m venv .venv` | `uv venv` |
| 装依赖 | `pip install fastapi` | `uv add fastapi` |
| 锁版本 | `pip freeze > requirements.lock`（容易忘） | 自动写 `uv.lock` |
| 还原环境 | `pip install -r requirements.lock` | `uv sync` |
| 跑脚本 | `python main.py` | `uv run main.py` |

阶段 1 用哪个都行，都练一遍最好。
