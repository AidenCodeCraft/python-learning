## 五、顺手补课：`uv` 是什么（他在第 1 题问的）

### 一句话

`venv` 管"用哪个 Python"，`uv` 把"建环境 + 装依赖 + 锁版本 + 跑命令"全包了，而且快得多。

### 对比他现在会的东西

| 你现在做的事 | 用 venv + pip | 用 uv |
|---|---|---|
| 建虚拟环境 | `python -m venv .venv` | `uv venv` |
| 装依赖 | `pip install fastapi` | `uv add fastapi` |
| 锁定版本 | `pip freeze > requirements.lock`（要自己记得做） | **自动写进 `pyproject.toml` + `uv.lock`** |
| 还原环境 | `pip install -r requirements.lock` | `uv sync` |
| 跑脚本 | `python main.py` | `uv run main.py`（自动确保环境对） |

### 为什么公司要求它

"依赖要锁定版本"这件事，`pip` 靠人肉自觉（`pip freeze` 经常忘），`uv` 是**默认行为**。
`uv.lock` 进了 Git，任何同事 `uv sync` 就能还原出**一模一样的依赖树**，不会出现"我这能跑你那不能跑"。

### 今天不用急

阶段 1 用哪个都行（都练一遍最好）。阶段 3 起正式统一用 `uv`。
`scripts\setup_env.ps1` 已经把它装进 `.venv` 了。
