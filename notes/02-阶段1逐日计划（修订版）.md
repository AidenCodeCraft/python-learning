## 二、每日节奏模板

**工作日（2 小时 = 120 分钟）**

| 时段 | 分钟 | 内容 |
|---|---:|---|
| 复习 | 0–15 | 昨天的自检清单 + 错题本朗读（出声念一遍） |
| 讲解 | 15–40 | 读当天 `README.md` 的"讲解+示例"，**并亲手把示例跑一遍** |
| 练习 | 40–100 | 60 分钟做题（按三档推进，见下） |
| 复盘 | 100–120 | 写 `mistakes/` 错题 + 填自检清单 + Git 提交 |

**周末（6 小时 = 360 分钟）**

| 时段 | 分钟 | 内容 |
|---|---:|---|
| 复习 | 0–20 | 前 3 天的自检清单 |
| 讲解 | 20–80 | 分 2~3 个模块，每讲完一个模块立刻跑示例 |
| 练习 | 80–260 | 3 小时做题 |
| 项目 | 260–330 | 组装成可运行产物 |
| 复盘 | 330–360 | 错题本 + Git 提交 + 阶段验收 |

> **上班时间只看"讲解+示例"和自检清单，不要做完整练习** —— 练习需要连续时间，碎片时间做会碎掉。

## 三、知识点三档推进规则（本课程新增，必须遵守）

每个知识点按档位走，**上一档没过不许跳**：

| 档 | 名称 | 具体做法 | 判定通过 |
|---|---|---|---|
| ① | **读改** | 照抄示例代码 → 改数据 → 改参数 → 看输出怎么变 | 能说出"我改了哪一行，输出为什么变" |
| ② | **填空** | 骨架代码挖 1~3 个空，你补 | 补完能跑通 |
| ③ | **默写** | 关掉所有参考，从零写 | 能跑通且能解释 |

只有第 ③ 档算"练习"。**卡住时先写思路，连续两次卡住我会升一级提示**（思路 → 伪代码 → 关键 API → 局部代码 → 完整答案）。

## 四、练习与答案的规则（本次修订）

- ❌ 不再在示例注释里写答案（原版 `print(a / b)  # 3.5` 这种）。
- ✅ 练习**只给预期输出**（"自检清单"），不给代码。
- ✅ 你写完 → 对照自检清单 → 自己判断对错 → 再提交给我。
- ✅ 提交格式固定：结论 / 正确点 / 具体问题 / 错因分析 / 最小修改建议 / 2~3 道变式题 / 需要复习的旧知识点 / 下一步任务。

## 五、与原版（DeepSeek 网页版）的差异，以及为什么改

| # | 原版 | 修订版 | 为什么 |
|---|---|---|---|
| 1 | D1（10-14）一天塞 4 个模块：变量与类型 + 运算符 + 条件 + 循环 | D1 只讲**对象模型**（名字绑定/可变性/别名/复制） | 你第 2 题答错了"引用"这件事，而它同时是**默认参数陷阱、浅拷贝、ORM 对象复用、FastAPI 请求体**的总根源。这里不补，后面全是坑 |
| 2 | D1 的练习 4 要求写 `def is_leap(year: int) -> bool`，但函数是 D2 才教 | 函数统一放到 D4 | 原版前后矛盾：让你用还没教的东西解题。这正是 10-13 那次挫败的成因 |
| 3 | 示例注释直接写答案 | 注释不写答案，练习给"预期输出"自检 | 违反"不要直接给答案"，而且会让人跳过思考 |
| 4 | async/await 作为阶段 1 正式知识点 | D5 只做 20 分钟"认知课"：能说清"遇到 I/O 等待时把时间让给别人"，不写代码；正式动手放阶段 3 | 脱离 FastAPI 讲 async 没有抓手，而且你第 7 题是"错误心智模型"，先纠错比先教语法重要 |
| 5 | 每天主题偏多 | **每天只压一个主题** | 上一轮的挫败说明：量超了就变成"不会→更不会" |
| 6 | 没有自检机制 | 每份练习配"预期输出"自检清单 | 你能自己判断对错，不用等我批改，反馈回路从 1 天缩到 1 分钟 |

## 六、阶段 1 验收标准（10-18 执行）

全部达标才算通过，**不通过就顺延阶段 2**：

1. 能独立写出 **100~150 行**可运行小脚本（待办清单 / 文件统计 / JSON 处理任一）。
2. 能解释并现场修正：`NameError`、`TypeError`、`IndexError`、`KeyError`、`ValueError`、`IndentationError`、`ImportError`、`AttributeError`。
3. 能用函数 + 模块拆分代码。
4. 能写 **3 个 pytest 测试**并跑通。
5. 能用 Git 完成分支 + 提交（提交信息符合 `feat:` / `fix:` 规范）。
6. 能说清：可变/不可变、别名/浅拷贝、默认参数陷阱、类属性 vs 实例属性。
